# 叁思坦科技品牌官网

这是一个面向K12学生家长的STEM教育培训品牌官网，基于 Vue 3 + Vite 构建，包含首页、服务项目、师资团队、学员案例和联系我们等页面。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 适配部署

适合部署到 Cloudflare Pages、Netlify、Vercel 或静态文件服务器，页面已使用相对路径输出兼容静态部署。

## 功能特性

- 响应式布局
- 多页面路由
- 首页品牌展示与转化入口
- 服务内容说明
- 师资团队介绍
- 案例筛选与详情展示
- 咨询表单交互

## 设计语言

- 专业稳重：蓝色与白色为主色
- 活力创新：适度使用渐变与卡片交互
- 家长信任：突出企业资质、案例、师资与评价
